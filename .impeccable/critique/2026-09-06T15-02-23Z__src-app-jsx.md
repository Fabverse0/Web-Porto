## Design Specificity Verdict

The portfolio's **data model and engineering substance** are genuinely authentic to a backend software engineer and systems architect (50,000 WebSocket fanouts, ClickHouse telemetry, Redis idempotency, Kafka event streams). 

However, the **visual interface suffers from a severe execution disconnect**:
1. **The Three Core Persona Components are Orphaned**: `Terminal.jsx`, `ScalarHub.jsx`, and `ScalarReference.jsx` are fully coded in `src/components/`, but are never imported or rendered in `App.jsx`, `Hero.jsx`, or `ProjectModal.jsx`. The site's primary technical selling points are invisible to visitors.
2. **Superficial Motion Tropes vs. Backend Engineering Aesthetics**: The hero centers a single column of text over an unconstrained 60fps particle canvas and wraps an entire paragraph in `VariableFontHover`, making text warp and jitter on hover while disabling text selection.
3. **Broken Data Binding in Architecture Topology**: In `ProjectModal.jsx:116`, the component attempts to read `{step.description}`, but the schema in `portfolioData.js` uses `desc`. As a result, clicking architecture nodes renders blank descriptions.

**Deterministic Scan**:
- Direct scan on `src public`: 0 primary AST rule violations in compiled JSX.
- Asset scan on `.`: 7 warnings, 1 advisory in static banner templates (`low-contrast` 4.1:1 text on `#09090B`, `dark-glow` shadows, `radial-spotlight-glow`).
- Manual code audit caught critical runtime failures: 1.4:1 contrast on skill level badges (`#FFCC00` on cream), dead `.dev` URLs, keyboard traps, and fake form submissions.

## Priority Issues

### [P0] 3 Core Components Orphaned (`ScalarHub`, `ScalarReference`, `Terminal`)
- **Why it matters**: `AGENTS.md` promises an interactive zsh CLI terminal and 100% Scalar OpenAPI 3.0 documentation. Because they are never rendered in `App.jsx`, `Hero.jsx`, or `ProjectModal.jsx`, visitors miss Fabian's most impressive engineering achievements.
- **Fix**:
  1. Refactor `Hero.jsx` into a 2-column layout: Left column with bio and CTAs; Right column mounting `<Terminal />`.
  2. Mount `<ScalarHub />` directly on the homepage between `Projects` and `Experience`.
  3. Add the 4th tab to `ProjectModal.jsx` to render `<ScalarReference project={project} />`.
- **Suggested command**: `$impeccable layout` / `$impeccable harden`

### [P0] Broken Architecture Topology Data Binding
- **Why it matters**: In `ProjectModal.jsx:116`, `{step.description}` evaluates to `undefined` because `portfolioData.js` defines `desc`. Clicking any architecture node shows a blank description.
- **Fix**: Update `ProjectModal.jsx` to read `step.desc || step.description`, and bind `nodeType`, `layer`, and `protocol` properly.
- **Suggested command**: `$impeccable harden`

### [P0] Dead Project Demo & Contact URLs
- **Why it matters**: `portfolioData.js` links live demos to `https://chat-gateway.dev` and `https://api-demo.dev`, causing immediate DNS NXDOMAIN errors. The cURL snippet uses dead `api.fab.dev`.
- **Fix**: Point demo links to active repositories, internal Scalar documentation routes, or honest coming-soon placeholders.
- **Suggested command**: `$impeccable clarify`

### [P1] Readability & Motion Fatigue in Hero Bio
- **Why it matters**: `VariableFontHover` wraps 210 characters into individual spans that jitter and change weight as the mouse moves, disabling normal text selection (`select-none`).
- **Fix**: Remove `VariableFontHover` from the paragraph; render clean, selectable body text with `Inter`. Restrict variable font hover strictly to the name display title.
- **Suggested command**: `$impeccable typeset`

### [P1] Severe WCAG Contrast & Keyboard Accessibility Failures
- **Why it matters**: Skill badges in `AboutSkills.jsx` (`#FFCC00` on `#FAF8F5`) yield 1.4:1 contrast. Theme toggle has no `onKeyDown`. `ProjectModal.jsx` has no `Escape` key listener or focus trap.
- **Fix**: Use darker text tokens with semi-transparent background pills; add `onKeyDown` handlers and `Escape` modal dismissal.
- **Suggested command**: `$impeccable audit`
