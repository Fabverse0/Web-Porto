## 2. Brand Voice & Tone

| Attribute | Guideline | Example |
|---|---|---|
| **Precise & Technical** | State concrete metrics (TPS, latency, uptime) rather than generic fluff. | *"50,000 active WebSockets with <5ms fanout"* instead of *"scalable chat"*. |
| **Pragmatic & DX-Focused** | Prioritize developer experience, OpenAPI standards, and clear documentation. | *"Documented with Scalar OpenAPI 3.0 specs and multi-language client code generators"*. |
| **Subtle Technical Humor** | Friendly, approachable CLI terminal easter eggs. | `sudo` ➡️ *"Access denied. Hire Fabian to unlock root permissions!"* |

## 3. Visual Identity & Color Palette

### Primary Palette (Light Monochromatic + Black Contrast)

| Color Name | Hex Code | Role | Usage |
|---|---|---|---|
| **Snow Light** | `#FAFAFA` | Base Background | Page background, clean spacing |
| **Pure White** | `#FFFFFF` | Card & Section | Cards, modals, contrast containers |
| **Jet Black** | `#09090B` | Contrast Anchor | Terminal window, primary buttons, headers |
| **Zinc Border** | `#E4E4E7` | Line Structure | Subtle grid dividers & borders |

### Accent Highlights

| Color Name | Hex Code | Role | Usage |
|---|---|---|---|
| **Emerald Green** | `#10B981` | Status Operational | Live API status lights, 200 OK responses, metrics |
| **Royal Blue** | `#2563EB` | Interactive Links | Hover indicators, Scalar badges, primary CTAs |

## 4. Typography Specifications

- **Display / Headings**: `Space Grotesk` (Weight: 600, 700, 800) — Bold, geometric, modern engineering vibe.
- **Code / Monospace**: `JetBrains Mono` (Weight: 400, 500, 700) — Terminal CLI, code snippets, cURL requests, metrics.
- **Body Text**: `Inter` (Weight: 400, 500, 600) — High readability, crisp paragraph text.
