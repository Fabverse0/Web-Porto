---

## 🌟 Key Features

- **Interactive CLI Terminal Widget**: Embedded zsh terminal supporting `help`, `bio`, `skills`, `projects`, `cv`, `contact`, and Easter Eggs (`sudo`, `ping`, `matrix`).
- **Scalar OpenAPI 3.0 Hub**: Powered by `@scalar/api-reference-react` for on-page live interactive OpenAPI spec rendering and multi-language client code generation (cURL, JavaScript, Go, Python).
- **4-Tab Project Detail Modals**:
  1. *Overview & Specs*
  2. *System Architecture Diagram Flowchart*
  3. *Production Benchmark Metrics* (12.5k TPS, <8ms Latency, 99.99% Uptime)
  4. *Scalar API Reference & Code Tester*
- **Interactive Skill Matrix Filtering**: Dynamic skill filtering that highlights and filters matching backend projects on click.
- **Light Monochromatic Aesthetic**: Built using `ui-ux-pro-max` guidelines featuring Pure Snow background (`#FAFAFA`) with high-contrast Jet Black containers (`#09090B`) and Emerald Green status lights (`#10B981`).
- **1-Click Quick Copy & Dual Contact**: Instant email copy, terminal `curl` request generator, and contact form dispatch.

## 🚀 Quick Start (Local Development)

```bash
# 1. Clone repository
git clone https://github.com/Fabverse0/Web-Porto.git
cd Web-Porto

# 2. Install dependencies
npm install

# 3. Start Vite development server
npm run dev

# App will run locally at http://localhost:3000/
```

---

## 📦 Production Build & Vercel Deployment

```bash
# Create production build
npm run build
```

This project includes a pre-configured `vercel.json` for zero-config SPA routing. Simply import `Fabverse0/Web-Porto` into Vercel for automatic global deployment.
